# 🖼️ Image to Text Conversion Using PaddleOCR

## 📖 Project Description

Image to Text Conversion is a Computer Vision project that uses PaddleOCR to extract text from images. The system reads an image, detects the text present in it, and displays the extracted text along with confidence scores.

This project demonstrates the practical application of Optical Character Recognition (OCR) for converting image-based text into machine-readable text.

---

## 🎯 Objectives

- Extract text from images automatically
- Perform Optical Character Recognition (OCR)
- Display detected text with confidence scores
- Understand image processing and computer vision concepts

---

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Image-to-Text-Conversion.git
cd Image-to-Text-Conversion
```

### 2. Install Required Libraries

```bash
pip install paddleocr
pip install paddlepaddle
pip install opencv-python
pip install numpy
```

Or install all dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ How to Run

Run the Python file:

```bash
python image_to_text.py
```

Enter the image path when prompted:

```text
C:\Users\Admin\Desktop\image\sample.jpg
```
